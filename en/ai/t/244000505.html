Applies to: all engines; all production periods

When the ignition is in the ON position, when the buttons located in the doors are operated the electric front windows only work manually.

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check:

  • That there are no obstacles preventing the travel of the window;
  • The operation of the electric windows

Move on to Step

1. Presence of obstacles

1. Restore the correct mechanical operation of the window opening/closing

2. The electric windows work manually (the window opens/closes with the button pressed) but not automatically

Move on to Step

1

SERVICES CONTROL UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the services control unit is working properly, in particular that a command from a window opening switch to the services control unit has a corresponding output power supply for the appropriate electric window motor,

See E3050 ELECTRIC FRONT WINDOWS

Move on to Step

Control unit not working

Replace the services control unit

2

ELECTRIC WINDOW CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the mechanical section of the window opening device is working properly and is correctly fastened

Move on to Step

1. Window opening device not correctly fastened or adjusted

1. Restore the operation of the window opening device

2. Electric window device faulty

2. Replace the window opening device

3

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
