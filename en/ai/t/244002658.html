Removing

Refitting

Drain the return pipe from the return solenoid valve to the injectors, following the instructions in the procedure:

Op. 1043A02 LPG SYSTEM LINES PIPE DRAINING OPERATIONS

Disconnect the negative battery terminal.

1. Disconnect the connector (1a) for the return pipe to the intermediate block (1b) for the return line; keep the seal underneath taking special care not to damage the pipe threaded seat.

2. Undo the connector (2a) on the rigid return pipe (2b) from the injectors; keep the seal underneath taking special care not to damage the pipe threaded seat.

3. Remove the flexible return pipe from the rigid pipe connector to the injectors.

Applies to: engines: 2.0 16V; all production periods

Removing

Position the flexible return pipe from the rigid pipe connector to the injectors complete with new seals.

Tighten the connector for the flexible pipe to the rigid return pipe from the injectors.
