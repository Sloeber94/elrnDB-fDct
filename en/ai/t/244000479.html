Applies to: all engines; all production periods

When the button in the switch unit is operated the hazard warning lights do not work.

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check whether the left and right direction indicators work properly with the ignition switched on.

Move on to Step

The direction indictors do not work

Proceed as instructed

See table I35 DIRECTION INDICATORS (TWO) RH AND LH NOT WORKING

1

TURN SIGNAL ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Turn signal fuses;
  • Connections between battery and underfacia junction unit
  • Connections between battery, ignition switch and underfacia junction unit
  • Connections between underfacia junction unit and switch control unit

Move on to Step

1. Component defective

1. Replace defective component (in the case of a fuse, find out what caused it to blow).

2. Connections interrupted

2. Repair the connections

See E2020 DIRECTION INDICATORS / HAZARD WARNING LIGHTS

2

SWITCH CONTROL UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Correct power supplies/earths to switch control unit
  • Check that when the switch in the switch unit is operated there is a corresponding battery voltage output from the switch unit to switch on the bulbs

Move on to Step

See E2020 DIRECTION INDICATORS / HAZARD WARNING LIGHTS

2. Switch control unit fault

2. Replace switch control unit

Op. 5505A24 W/L AND SERVICE SWITCH MOUNT - R+R

3

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
