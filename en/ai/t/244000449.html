B25 THE ENGINE STARTS UP AND CUTS OUT AFTER A FEW SECONDS

Path

Kind

Applies to

Interactive page

Applies to: all engines; all production periods; only with equipment: BIPOWER

When engine fuel supply is set to methane using the appropriate selector, the engine starts normally in petrol mode but then goes off after a few seconds and does not switch to methane.

Applies to: all engines; all production periods; only with equipment: BIPOWER

Applies to: all engines; all production periods; only with equipment: GPL

Check that the LPG pump current sensor is correctly inserted in its seat.
