I20 FOG LIGHTS NOT WORKING

Applies to: all engines; all production periods

The fog light does not work when the button on the relevant switch unit is operated with the key ON and the side lights - dipped beams on.

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

1

INDIVIDUAL LIGHT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the bulbs and associated bulb holder;

Move on to Step

1. Bulbs damaged

1. Change the bulbs

Op. 5540D14 L/H OR R/H FOG LAMP BULB (ONE) - R+R

2.Front light cluster fault

2. Repair or change the front light cluster

Op. 5540D13 RIGHT FOG LIGHT - R.R.

2

FOG LIGHT ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Fog light fuses;
  • Connections between battery, engine bay control unit, fog light relay and bulbs;
  • Bulb earth

Move on to Step

1. Component defective

1. Replace defective component (in the case of a fuse, find out what caused it to blow).

2. Connections interrupted

2. Repair the connections

See E2030 FOG LIGHTS

3

FOG LIGHT ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Connections between battery, ignition switch, facia control unit, engine bay control unit, fog light relay and switch control unit
  • Connections between stalk unit and switch control unit

Move on to Step

1. Component defective

1. Replace defective component (in the case of a fuse, find out what caused it to blow).

2. Connections interrupted

2. Repair the connections

See E2030 FOG LIGHTS

4

STEERING COLUMN SWITCH UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the stalk unit is working properly: particularly the side light activation data output

See E2030 FOG LIGHTS

Move on to Step

Stalk unit not working properly

Replace the steering column switch unit

Op. 5550A12 COMPLETE STALK UNIT - R+R FOR VERSIONS WITH AIR BAG

5

FOG LIGHT RELAY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the fog light relay is working properly

See E2030 FOG LIGHTS

Move on to Step

Fog light relay not working properly

Change the dipped beam relay

Op. 5550A12 COMPLETE STALK UNIT - R+R FOR VERSIONS WITH AIR BAG

6

IGNITION SWITCH CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the ignition switch is operating correctly: particularly the fog lamp relay power supply

See E2030 FOG LIGHTS

Move on to Step

Ignition switch fault

Repair or replace the ignition switch

Op. 5520A12 IGNITION SWITCH ASSEMBLY - R R FOR VERSIONS WITH AIR BAG

7

SWITCH CONTROL UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Correct power supply to switch control unit
  • Check that side light activation output data is present when the stalk switch wheel is turned
  • Check that an earth signal is generated to control the fog light relay when the fog light button is activated

Move on to Step

1. Connections interrupted

1. Repair the connections

See E2030 FOG LIGHTS

2. Switch control unit fault

2. Change the switch control unit

8

ENGINE BAY CONTROL UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Correct power supply to the engine bay control unit;
  • Check that an earth signal is generated to control the dipped beam relay when the fog light button is activated

Move on to Step

1. Connections interrupted

1. Repair the connections

See E2030 FOG LIGHTS

2. Engine bay control unit fault

2. Change the engine bay control unit

Op. 5505A13 SUPPLEMENTARY JUNCTION CONTROL UNIT IN ENGINE BAY - R R

9

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
