If the display is not on, this is due to problems with the tacograph control unit power supply.

Applies to: all engines; all production periods

The error code remains on the display until the cause that gave rise to the error is removed.

Applies to: all engines; all production periods

1

CHECK ON ERROR TYPE

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check for error codes that appear in the tables in the tacograph User Handbook.

Move on to Step 2

Error detected from error code

Correct operation restored

2

CHECK ON ERROR TYPE

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the vehicle at a standstill and key ON, when the "M" key on the tachograph is pressed twice briefly.

Check for error code "900A or 900B". (this error is suppressed for about 10 second after key ON).

See Test 5560C OTHER INSTRUMENTS

Move on to Step 3

1. If error code 900A or 900B is present with no messages from the speedometer pulse generator controller", possible cause: wiring faults

1. Restore correct operation of speedometer pulse generator power supply/wiring.

See E4025 TACHOGRAPH

2. If error code 900A or 900B is present with no messages from the speedometer pulse generator controller", possible cause: errors in the speedometer pulse generator

2. replace the speedometer pulse generator.

See E4025 TACHOGRAPH

3. If error code 900A or 900B is present with no messages from the speedometer pulse generator controller", possible cause: protocol error/terminal resistance not present

3. Restore terminal resistance connection.

ACTION

CHECK ON ERROR TYPE

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the vehicle at a standstill and key ON, when the "M" key on the tachograph is pressed twice briefly.

Check for error code "9053 or 9064" (the tachograph detected a difference of more than 2 minutes between the time shown on the display and the tacograph disc insertion time).

Move on to Step 7

1. Error code 9053 or 9064 found, possible cause: tachograph disc incorrectly positioned.

1. With the vehicle at a standstill and the engine running, remove the tachograph discs inserted and close the disc holder cassette.

2. Error code 9053 or 9064 found, possible cause: fault repeated.

2. Replace the tachograph

Op. 5560C22 TACHOGRAPH - R.R.

ACTION

With the vehicle at a standstill and key ON, when the "M" key on the tachograph is pressed twice briefly.

Check for error code "9060" (Error in handling disc holder cassette).

Move on to Step 8

1. Error code 9060 found, possible cause: tachograph disc/discs not inserted correctly or damaged. An object may be exercising pressure on the lower side of the tachograph case.

1. Restore the disc holder cassette to correct working order and/or position the tachograph discs correctly.

2. Error code 9060 found, possible cause: mechanical impediment to opening of the tacograph disc holder cassette.

2. Replace the tachograph
