When the stalk switch is operated with the key ON, the windscreen wash/wipe function does not work

Applies to: all engines; all production periods

PRELIMINARY CHECK

PROBLEMS ENCOUNTERED

ACTION

Check fuse condition

See E3020 WINDSCREEN WASH/WIPE

Move on to Step

Fuse/s blown

Replace fuse/s and find out what could have caused them to blow

1

WINDSCREEN WASH/WIPE ELECTRIC CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Connections between battery and engine bay junction unit
  • Connections between engine bay junction unit and underfacia junction unit
  • Connections between battery, ignition switch and underfacia junction unit
  • Connections between underfacia junction unit and steering column switch unit
  • Connections between underfacia junction unit and windscreen wiper motor
  • Connections between engine compartment junction unit and windscreen wiper motor
  • Connections between steering column switch unit and windscreen wiper motor
  • Connections between steering column switch unit and electric pump motor
  • Stalk unit earth
  • Windscreen wiper motor earth

Move on to Step

Connections interrupted

Repair the connections

See E3022 HEADLAMP WASHER

2

STEERING COLUMN SWITCH UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

  • Correct stalk unit power supply/earths
  • Check there is an earth signal output to the windscreen wiper motor when the steering column switch unit lever is operated

Move on to Step

1. Power supplies/earths incorrect

1. Restore correct power supplies/earths

See E3022 HEADLAMP WASHER

2. Stalk unit not working properly

2. Replace the steering column switch unit

Op. 5550A12 COMPLETE STALK UNIT - R+R FOR VERSIONS WITH AIR BAG

WINDSCREEN WIPER MOTOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

See E3022 HEADLAMP WASHER

  • Correct windscreen wiper motor power supply/earths;
  • Check that when there is an earth signal from the steering column switch unit to the windscreen wiper motor the latter is working

Move on to Step

1. Power supplies/earths incorrect

1. Restore correct power supplies/earths

See E3022 HEADLAMP WASHER

2. Windscreen wiper motor faulty;

2. Replace the windscreen wiper motor
