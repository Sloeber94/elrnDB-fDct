Applies to: engines: 2.0 16V; all production periods

Operational Description

The inertia switch I050 provides the reference earth for the pump N041, at pin 3, for the methane supply solenoid valves L060 and for the methane regulation solenoid valve L061.

  • provides the fuel system supply mode (petrol/methane) for the methane injection control unit M019 from pin 2;
  • receives the fuel system supply mode (petrol/methane) for the methane injection control unit M019 from pin 4;
  • receives the signal for the methane level inside the canisters from pin 1.

The engine management control unit M010 is connected from pins E4 and D4 connector B to the engine coolant temperature sensor K036.
