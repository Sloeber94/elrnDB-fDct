When the device which controls the headlamp alignment is operated (with the dipped headlamps on) it does not work. If the dipped headlamps are not working either

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

1

HEADLAMP ALIGNMENT ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Connections between engine compartment control unit and headlamp alignment motors;
  • Connections between engine compartment control unit and headlamp alignment control;
  • Connections between headlamp alignment control and headlamp alignment motors;
  • earth for headlamp alignment motors and headlamp alignment control

Move on to Step

1. Connections not correct

1. Repair the connections

See E3080 HEADLAMP AGLINMENT CORRECTOR

2. Earths defective

2. Repair the earth contacts

See E3080 HEADLAMP AGLINMENT CORRECTOR

2

HEADLAMP ALIGNMENT CONTROL CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the operation of the headlamp alignment control

See E3080 HEADLAMP AGLINMENT CORRECTOR

Move on to Step

Headlamp alignment control faulty

Replace the headlamp alignment control

3

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
