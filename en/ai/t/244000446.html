Applies to: all engines; all production periods

The engine does not start. When the key is turned the instruments light up as normal, the starter motor turns, but the engine does not start up.

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Turn the key ON and check that the initial check on the MIL and CODE warning lights takes place.

Then check:

  • that the inertia switch has cut in;
  • presence of fuel in the tank;
  • air intake circuit;
  • correct operation of the exhaust manifolds.

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

First check for petrol in the tank (because the engine always starts in petrol mode whether set to petrol or methane mode).

Check the inertia switch cuts in.

Check the following, in order:

  • petrol pump fuse condition;
  • relays for methane engine management unit correctly fitted
  • status of spark plugs and leads;
  • condition of the air intake circuit;
  • possible catalytic converter obstruction
  • no water, other fluids or dirt in the fuel tank;

PRELIMINARY CHECKS

PROBLEMS ENCOUNTERED

ACTION

The MIL warning light should come on and then go out when the engine is started up, whilst the CODE warning light should come on for about 4 seconds and then go out

Then check:

  • that the inertia switch has not been operated;
  • presence of fuel in the tank;
  • air intake circuit;
  • air closure throttle on chamber open;
  • correct operation of the exhaust manifolds
