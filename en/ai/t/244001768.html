Applies to: all engines; all production periods

Description

The front door windows are operated by switches on the facia.

Operation is manual: the glass goes up/down only with the key pressed. Both windows are operatd only with key ON (INT).

The window circuit is protected by a special fuse housed in the underfacia junction unit and is managed by a dedicated control unit (ABI).
