The screen washer does not work when the steering column switch unit lever is operated with the ignition on.

Applies to: all engines; all production periods

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check:

See E3020 WINDSCREEN WASH/WIPE

  • the condition of the fuses
  • The level of the washer fluid

Move on to Step

1. Fuse/s blown

1. Replace fuse/s and find out what could have caused them to blow

2. Fluid level too low

2. Add fluid, checking for possible leaks

1

STEERING COLUMN SWITCH UNIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

  • Correct stalk unit power supply/earths
  • Check that an operational output voltage to the electric pump motor is present when the stalk switch is operated

Move on to Step

1. Power supplies/earths incorrect

1. Restore correct power supplies/earths

See E3022 HEADLAMP WASHER

2. Stalk unit not working properly

2. Replace the steering column switch unit

Op. 5550A12 COMPLETE STALK UNIT - R+R FOR VERSIONS WITH AIR BAG

2

ELECTRIC PUMP MOTOR CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the operation of the electric pump motor

See E3022 HEADLAMP WASHER

Move on to Step

Motor defective

Replace the motor

3

SCREEN WASHER ELECTRICAL CIRCUIT CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the following, in order:

  • Connections between battery and engine bay junction unit
  • Connections between engine bay junction unit and underfacia junction unit
  • Connections between battery, ignition switch and underfacia junction unit
  • Connections between underfacia junction unit and steering column switch unit
  • Connections between steering column switch unit and electric pump motor
  • Stalk unit earth
  • Electric pump motor earth

Move on to Step

Connections interrupted

Repair the connections

See E3022 HEADLAMP WASHER

4

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present
